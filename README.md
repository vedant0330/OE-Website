# Horizon College Student Result Portal

A simple college project website for looking up a sample student record. Enter the student's full name and roll number; both must match before the record is shown.

## Files

- `index.html` — the complete website. It includes the sample records and runs without a build step or external libraries.
- `student_results.xlsx` — the sample student details spreadsheet. It can be opened in Excel or imported into Google Sheets.

## Run the website

Open `index.html` in a web browser. No installation is required.

## Publish with GitHub Pages

1. Create a GitHub repository for the project.
2. Upload `index.html`, `README.md`, and `student_results.xlsx` to the repository's root folder.
3. In the repository, open **Settings → Pages** and choose deployment from the `main` branch and the root folder.
4. Save the Pages settings. GitHub will provide the published website address after deployment.

## Sample data note

The college name, course, class/year, and attendance values are examples for this project. The website uses its own copy of the sample records in `index.html`; changing the spreadsheet does not automatically change the website. Update both files if you edit the sample records.
